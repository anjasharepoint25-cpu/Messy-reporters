# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Our Standards

Participants are expected to be respectful, constructive, and professional.
Harassment, discriminatory language, and personal attacks are not acceptable.

## Enforcement

Maintainers may remove comments, close issues, or restrict participation for
behavior that violates these standards.

## Reporting

Report conduct concerns privately to the project maintainers. Maintainers will
review reports and respond in a way that protects contributors and the project.
