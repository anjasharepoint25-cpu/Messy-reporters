# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project follows semantic
versioning once the first stable release is published.

## [0.1.0] - 2026-05-31

### Added

- Initial CSV and Excel loading support.
- Data cleanup for whitespace, empty rows, empty columns, and column names.
- JSON and Markdown report rendering.
- Python API and command-line interface.
- Initial pytest test suite.
